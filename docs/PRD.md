# PRD — سند نیازمندی محصول

## ۱) مسئله

سازمان‌های ایرانی می‌خواهند از مدل‌های هوش مصنوعی «کارمند» بسازند، نه «چت‌بات».
کارمند یعنی کسی که:

1. با پرامپت و لحن سازمان حرف می‌زند (فارسی)،
2. به مدل‌های مختلف وصل است و با تغییر قیمت/مدل جدید، تنظیمش عوض می‌شود،
3. به ابزارهای واقعی دسترسی دارد (تلگرام، ایمیل، اکسل، نرم‌افزار حسابداری، تلفن)،
4. کارهای حساس را بدون تأیید انسان انجام نمی‌دهد،
5. هزینه‌اش شفاف و به تومان قابل پیگیری است.

## ۲) پرسوناها

| پرسونا | نیاز اصلی | نقش در سیستم |
|---|---|---|
| مالک کسب‌وکار | هزینه و نتیجه | `owner` |
| مدیر عملیات | ساخت ایجنت و وظیفه | `admin` |
| کارشناس | اجرای ایجنت و تأیید | `operator` |
| ناظر / حسابرسی | دیدن، بدون تغییر | `viewer` |
| ایجنت (نرم‌افزاری) | ابزار و بودجه‌ی محدود | موجودیت `agents` |

## ۴) خارج از دامنه (Out of scope) — تصمیم آگاهانه

- اپ موبایل بومی
- موتور RAG/حافظه‌ی برداری (جدول‌ها آماده‌اند، پیاده‌سازی نشده)
- زمان‌بند اجرای وظایف (cron) — طراحی شده، اجرا نمی‌شود
- اجرای گراف جریان (نودهای شرط/موازی) — اعتبارسنجی و ذخیره هست، اجرا نه
- فاکتور رسمی و مالیات (به‌دلیل نبود درگاه در فاز اول)
- بازارچه‌ی ابزار (marketplace)

## ۷) ریسک‌های محصول

| ریسک | اثر | راهکار فعلی |
|---|---|---|
| قطع دسترسی به پروایدرهای خارجی از ایران | توقف سرویس | پشتیبانی از ریسلرهای سازگار + `meta.proxy` صریح |
| محدودیت API شبکه‌های اجتماعی | بن شدن اکانت | API رسمی + تأیید انسانی برای ارسال |
| مجوز تلفن | توقف ماژول صدا | شروع با سافت‌فون روی کانکتور |
| دسترسی ایجنت به فایل | نشت/خرابکاری | allow-list دوطرفه + تأیید + حسابرسی |
| جهش قیمت ارز | ضرر مالی | نرخ ارز در دفتر مصرف snapshot می‌شود |
