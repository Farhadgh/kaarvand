## وضعیت در یک نگاه

| مورد | مقدار |
|---|---|
| جداول دیتابیس | ۴۲ (۱۴ مایگریشن، RLS روی ۱۹ جدول) |
| عملیات API | ۱۱۱ (۸۲ مسیر) + ۱ WebSocket |
| تست خودکار | ۲۵۲ بک‌اند + build/typecheck پنل |
| پنل وب | Next.js 15، ۱۹ مسیر، RTL + جلالی (قدم ۷، ۹، ۱۰، ۱۴) |
| پرامپت پیش‌فرض (فارسی) | ۱۳ |
| نوع آداپتور پروایدر | ۱۲ |
| عملیات اسکریپت اقدام (کانکتور) | ۲۴ |
| برنامه‌های کاتالوگ | ۲۵ (ابر + برنامه‌های دستگاه) |
| کانال ورودی (وبهوک) | تلگرام + واتساپ Cloud API |
| زبان محصول | فارسی (RTL، تقویم جلالی، ارقام فارسی) |
| وضعیت درگاه پرداخت | غیرفعال (حالت رایگان، پورت آماده) |

## قواعد خواندن این مستندات

- هر جا «کد خطا» آمده (مثل `auth.invalid_credentials`)، **قرارداد بین بک‌اند و فرانت** است؛
  متن فارسی در فرانت ساخته می‌شود و بک‌اند هرگز پیام فارسی برنمی‌گرداند.
- هر جا «⚠️ بک‌اند ندارد» آمده، یعنی برای آن قابلیت باید endpoint جدید اضافه شود
  (در [roadmap.md](roadmap.md) فهرست شده‌اند).
- نمونه‌ها با `curl`/PowerShell نوشته شده‌اند و روی سرور محلی قابل اجرا هستند.
